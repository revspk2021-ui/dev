# Free mock demonstration

`mock-demo.mp4` is a real 1080×1920 MP4 rendered locally by FFmpeg. Its illustrations are mock placeholders and its audio is a demonstration tone, not an ElevenLabs voice recording. No paid provider request was made.

To create an interactive sample project on your own computer, follow the main README, stop the studio, and run:

```bash
.venv/bin/python -m app.sample
./start.sh
```

This generates a separately labelled, pre-approved demo in your own local database. Your production projects still require explicit script and image approvals.
